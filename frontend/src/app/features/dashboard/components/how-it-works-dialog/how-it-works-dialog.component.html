How LabInsight works

LabInsight is a configurable laboratory operations dashboard built with synthetic data.

What does this dashboard show?

LabInsight provides an operational overview of a fictional diagnostic laboratory network using synthetically generated laboratory analysis data.

The dashboard can visualize:

  • Analysis volume — how the number of received analyses develops over time
  • Analysis status — distribution of completed, processing, delayed, pending and cancelled analyses
  • Processing time — average time required to process laboratory analyses
  • Laboratory workload — analysis volume across different laboratory locations
  • Priority distribution — distribution between normal, high and urgent analyses
  • Completion rate — percentage of received analyses successfully completed
  • Analysis categories — distribution across Hematology, Clinical Chemistry, Microbiology and Molecular Diagnostics
  • Delayed analyses — analyses exceeding their expected processing time
  1. Choose data Select the laboratory metric you want to analyze.
  2. Pick a visualization Choose one of the compatible visualization types.
  3. Configure Set the available filters and options for the selected metric.
  4. Add to dashboard Create the widget and arrange it on your dashboard.

Customize your dashboard

You can edit, delete and reorder widgets at any time. Use “Move widgets” to rearrange the dashboard.

All displayed laboratory data is synthetically generated. No real patient or medical data is used.
